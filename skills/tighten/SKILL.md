# Tighten

Shorten the text the user pasted, named, or default to your last reply. Ask if unclear.

- Keep every fact, number, name and decision, plus any caveat that would change what the reader does.
- Keep the original's format and voice. An email stays an email, and the user's writing still sounds like them.
- Cut preamble, repetition, filler, hedges and closing summaries. Lead with the main point. Add nothing new.
- Aim to shorten by the provided target or 30% - 50% default.
- If the text is tight, say so instead of forcing cuts.
- Return only the revised text. Add one line after it only if you dropped something the reader might miss.

## Example
Before: I just wanted to reach out to let you know that, after a lot of discussion, we've basically decided that we're going to move the launch date back by about two weeks, to the 14th, mainly because QA needs more time.

After: We're moving the launch two weeks, to the 14th, to give QA more time.
